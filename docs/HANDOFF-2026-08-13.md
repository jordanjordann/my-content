## 9. Process lessons that cost real time this session

1. **Fixtures and test helpers that don't reproduce production are the #1 escape route.** #145's kind-badge bug and #200's pagination test both passed green while proving nothing. Ask of every test: *does the fake reproduce production's rule, or a convenient approximation?*
2. **Re-run mutation proofs yourself; never read them off a report.** A developer reported "both mutations killed"; the reviewer re-ran and found one survived. Another reported "all 4 cases fail individually"; the true result was 3 of 4, masked by an aggregate count.
3. **A test that cannot fail is worse than no test.** Two shipped this session (`checked={column.locked || …}` hardcoded true; a header lookup that matched an unrelated sub-header).
4. **PR bodies become squash-commit messages.** Several carried claims that were false by merge time. Every claim must be literally true at push time.
5. **Agents must never invent user-facing copy.** Multiple agents correctly stopped and flagged instead. That discipline is why the DESIGN docs are still trustworthy — protect it.
6. **The owner reading the UI found bugs no audit did.** Two screenshots this session produced more real findings than a full code audit. Ask for them.
