Design review — Ticket #96: Four states: Hidden · 0 · — (unknown) · plays-not-views

The four engagement-count states

The same treatment is used everywhere a view / play / like count appears. Distinguishable by icon + text, never color alone.

State 1 · Disabled by creator
Hidden i The creator turned off view and like counts on this post. This is a creator setting — not zero, and not missing data.

Neutral info icon + tooltip. Hover or keyboard-focus the icon.

State 2 · Genuine zero
0

A real, measured zero. Full-strength text — it's trustworthy data.

State 3 · Unknown / never fetched
—

Em dash, muted. No icon. "We don't have this," distinct from "it was zero."

State 4 · Views 0, plays exist
116.3K plays 116.3K plays

Show the real play count, explicitly labelled plays — never the false "0 views".

Count columns are right-aligned (numeric convention). Non-numeric states ("Hidden", "—") stay right-aligned in-column and sort to the BOTTOM.
